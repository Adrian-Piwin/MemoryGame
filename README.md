# Animal Match

Version `1.2.1`

A browser memory game built with [Kenney's Animal Pack Redux](https://kenney.nl/assets/animal-pack-redux) (CC0).

## Play

[Play on GitHub Pages](https://adrian-piwin.github.io/MemoryGame/)

Or open `index.html` locally.

## Modes

| Mode   | Pairs | Grid | Peek |
|--------|-------|------|------|
| Easy   | 6     | 3×4  | 8s   |
| Medium | 8     | 4×4  | 4s   |
| Hard   | 12    | 4×6  | 2s   |
